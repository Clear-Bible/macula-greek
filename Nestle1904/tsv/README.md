# TSV

`macula-greek-Nestle1904.tsv` holds the word-level data from the `lowfat` XML as a
flat table: one row per `<w>`, no syntactic tree structure. It is generated by
the [tsv-transform](../../pipelines/tsv-transform) pipeline, which runs
`mappings/greek-lowfat-to-tsv.xq` through SaxonC-HE:

```shell
cd pipelines/tsv-transform
poetry install
poetry run python main.py Nestle1904
```

Pass `all` instead of `Nestle1904` to regenerate both corpora.

See [the pipeline README](../../pipelines/tsv-transform/README.md) for the two
Saxon configuration properties the transform depends on, what happens when
either is missing, and how to recover from a short result. Both were BaseX
flags before the pipeline replaced `mappings/generate-tsv.sh`.

## Reviewing a diff

[csv-diff](https://pypi.org/project/csv-diff/) is useful for summarizing what
actually changed. Take the committed copy from git rather than renaming files,
so there is nothing to clean up afterwards and no chance of leaving an untracked
`-original.tsv` behind:

```shell
# from the repository root, before regenerating
git show HEAD:Nestle1904/tsv/macula-greek-Nestle1904.tsv > /tmp/macula-greek-Nestle1904-original.tsv

# regenerate as above, then
pip3 install csv-diff
csv-diff --key="xml:id" --json /tmp/macula-greek-Nestle1904-original.tsv \
    Nestle1904/tsv/macula-greek-Nestle1904.tsv

# optionally use jq (https://jqlang.github.io/jq/) to get a list of changed ids
csv-diff --key="xml:id" --json /tmp/macula-greek-Nestle1904-original.tsv \
    Nestle1904/tsv/macula-greek-Nestle1904.tsv \
    | jq '.changed | .[] .key' -r
```
